# Unused Dictionary Words Webpage

This project is a simple multi-page dictionary-style website built with **HTML** and **CSS**. It presents a collection of lesser-used or uncommon dictionary words. Each word is a hyperlink that opens a separate window showing more details about the word, including examples, meanings, and structured lists/tables.

## ✨ Features

- Landing page with list of dictionary words
- Hyperlinks open in a new window
- Individual word pages include:
  - Word definitions
  - Usage in sentences
  - Synonyms/antonyms
  - Tables and lists for structure
- Colorful and responsive UI
- Developer name and ID displayed on screen

## 🛠️ Technologies Used

- HTML5
- CSS3
